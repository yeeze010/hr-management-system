# 权限矩阵、报表指标、告警通知与附件管理

## 权限模型

权限由四层组成：

1. 菜单权限：用户能否进入某个模块。
2. 按钮权限：新增、编辑、删除、导入、导出、审批等动作。
3. 数据权限：全公司、本部门、本部门及下级、本人、自定义范围。
4. 字段权限：薪资、证件号、手机号、合同附件等敏感字段脱敏或隐藏。

| 规则 | 触发条件 | 通知对象 | 渠道 | 处理要求 |
|---|---|---|---|---|

## 文件附件管理

### 附件分类

- 员工基础附件：身份证、学历证明、照片。
- 合同附件：劳动合同、续签协议、保密协议。
- 证书附件：资格证书、技能证书、培训证书。
- 流程附件：入职材料、离职交接、调岗说明、请假证明。
- 报表附件：导出文件、验收归档文件。

### 存储规范

- 使用 MinIO 作为对象存储。
- 文件元数据保存在 `file_object` 表。
- 业务表只保存 `file_id` 或附件关联表。
- 文件路径按业务域分桶或前缀：`employee/`、`contract/`、`certificate/`、`workflow/`、`report/`。

### 权限规则

- 附件下载必须校验业务数据权限。
- 合同、证件、薪酬相关附件默认敏感。
- 普通员工只能查看本人授权附件。
- 导出和下载敏感附件必须记录审计日志。

### 验收要求

- 支持上传、预览、下载、删除、归档。
- 上传限制：类型、大小、病毒扫描预留接口。
- 删除采用逻辑删除，保留审计记录。
- 文件丢失或 MinIO 不可用时有明确错误提示。
