# GitHub 开源 HR 产品功能参考

本项目仅参考成熟开源产品的模块边界与业务闭环，不复制其代码或界面。

## 参考项目

| 项目 | GitHub | 参考重点 | 本项目落地 |
|---|---|---|---|
| Frappe HR | https://github.com/frappe/hrms | 员工全生命周期、假勤余额、费用申请、绩效、移动自助 | 招聘转入职、员工服务台、生命周期推进、假勤与绩效 |
| OrangeHRM | https://github.com/orangehrm/orangehrm | 企业级员工信息、假勤、招聘与自助服务 | 组织员工档案、招聘流程、员工服务请求 |
| IceHrm | https://github.com/gamonoid/icehrm | 模块化 HR 管理与员工自助 | 服务台、资产台账、合规提醒 |

## 本轮增强

1. 招聘与入职：开放职位指标、候选人流程、阶段推进、候选人录入、入职准备度。
2. 员工服务台：假期余额、证明与费用服务、SLA、资产台账、合规提醒。
3. 产品闭环：候选人推进至待入职后衔接员工档案与入职流程；服务请求完成后保留状态结果。

## 后续工程化方向

1. 将招聘职位、候选人、面试评价、Offer 和入职清单持久化到 PostgreSQL。
2. 为员工服务请求增加审批流、SLA 规则、消息通知和审计日志。
3. 将资产领用与入转调离流程关联，并接入 MinIO 附件凭证。
