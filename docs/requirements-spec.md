# 人事全流程与组织效能管理系统需求规格说明

## 1. 项目目标

建设一套面向中大型企业的人事全流程与组织效能管理系统，统一管理员工主数据、组织与岗位、入转调离、审批流、合同与培训、基础报表和权限控制，支撑 HR、部门负责人和管理层的日常管理与统计决策。

## 2. 角色范围

| 角色 | 典型职责 | 核心诉求 |
|---|---|---|
| 系统管理员 | 组织、用户、权限、参数维护 | 系统初始化与权限治理 |
| HR 专员 | 员工档案、合同、异动、资料维护 | 主数据准确、流程可追踪 |
| HR 经理 | 编制与审批、风险预警、报表审核 | 全局监控与合规 |
| 部门负责人 | 申请编制、审批异动/请假/转正 | 快速审批与人员掌握 |
| 普通员工 | 查看档案、提交流程申请 | 自助办理 |
| 管理层 | 查看人员结构、流失、招聘与效率报表 | 决策分析 |

### 3.1 核心模块

5. 报表概览
6. 部署与验收材料

## 4. 业务流程

### 4.1 入职建档流程

1. HR 创建员工档案并录入基础信息
2. 系统生成员工编号并校验唯一性
3. 附件和合同信息补录
4. 档案进入“在职/试用/待入职”状态

### 4.2 转正/异动审批流程

1. 业务部门或 HR 发起流程
2. 直属主管审批
3. HR 经理复核
4. 审批完成后同步员工状态、岗位或部门
5. 记录审计日志

### 4.3 合同到期预警流程

1. 系统按天扫描未来 30/60/90 天到期合同
2. 生成工作台预警和报表风险项
3. HR 跟进续签、终止或转劳务处理

## 9. 报表指标

### 9.1 核心指标

1. 在册人数
2. 本月入职人数
3. 本月离职人数
4. 合同 30/60/90 天到期人数
5. 试用期待转正人数
6. 待审批任务数
7. 部门编制达成率
8. 档案完整率

### 9.2 风险指标

1. 超时未处理审批数
2. 缺证件/缺附件档案数
3. 编制超员部门数
4. 连续异常考勤人数

## 10. 非功能要求

- 响应时间：常用列表接口 P95 小于 1 秒
- 安全：账号鉴权、权限校验、密码加密、审计日志
- 可运维：容器化部署、配置外置、健康检查
- 可扩展：模块化领域设计，便于后续接入考勤、薪酬、培训

## 11. 里程碑建议

1. M1：完成真实数据库接入、员工档案 CRUD、基础 RBAC
2. M2：完成入转调离流程、合同管理、审计日志
3. M3：完成报表指标、自动化测试、预发验收
