# 验收标准与里程碑计划

## 验收标准

| 类别 | 标准 |
|---|---|
| 功能验收 | P0 功能全部完成，员工档案、组织岗位、入转调离、合同附件、权限审计可用 |
| 流程验收 | 入职、转正、调岗、离职、请假、加班流程可发起、审批、归档 |
| 数据验收 | 员工、部门、岗位、合同、证书、经历、流程记录数据一致 |
| 权限验收 | 菜单、按钮、数据范围、敏感字段、附件访问权限正确 |
| 报表验收 | 人员结构、异动、合同到期、考勤、绩效、培训报表口径明确 |
| 附件验收 | 支持上传、预览、下载、权限校验、审计记录 |
| 性能验收 | 员工列表常规查询 2 秒内返回，核心报表 10 秒内返回 |
| 安全验收 | 无高危漏洞，越权访问被拦截，敏感操作有审计 |
| 部署验收 | Docker 启动成功，Nginx 代理正常，健康检查通过 |
| 交付验收 | 需求、设计、接口、测试、部署、验收、GitHub 规范文档齐备 |

## 里程碑计划

| 里程碑 | 周期 | 目标 | 交付物 |
|---|---|---|---|
| M1 工程骨架 | 第 1-2 周 | 前后端工程、Docker、文档框架 | 可运行 MVP、工程规范 |
| M2 基础平台 | 第 3-4 周 | 登录、权限、用户、角色、字典、审计 | 基础平台可用 |
| M3 组织与员工 | 第 5-7 周 | 组织岗位、职级编制、员工档案、合同证书经历 | 员工主数据闭环 |
| M4 生命周期流程 | 第 8-10 周 | 入职、转正、调岗、离职、流程审批 | 入转调离可验收 |
| M5 日常人事 | 第 11-13 周 | 考勤、请假、加班、绩效、培训 | 日常 HR 运营可用 |
| M6 报表与归档 | 第 14-15 周 | 报表、告警、附件、导出、审计 | 报表归档可用 |
| M7 UAT 与上线 | 第 16 周 | UAT、部署、培训、验收、Release | `v1.0.0` 验收版本 |

## 验收交付清单

- 需求规格说明。
- 概要设计与系统架构。
- 数据库表设计。
- API 接口规划。
- UI 页面清单与交互说明。
- 权限矩阵。
- 测试计划与测试报告。
- 部署手册。
- 操作手册。
- 验收报告。
- GitHub Release 归档。

## 封版流程

1. 从 `develop` 创建 `release/v1.0.0`。
2. 冻结需求，只允许修复验收缺陷。
3. 执行全量回归和 UAT。
4. 输出测试报告、部署记录、验收报告。
5. 合并 `release/v1.0.0` 到 `main`。
6. 打 tag：`v1.0.0`。
7. 创建 GitHub Release，归档交付物。
