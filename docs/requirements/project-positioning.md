# 项目定位、用户角色与建设目标

## 项目定位

《人事全流程与组织效能管理系统》面向企业人力资源部门、业务部门主管、员工与管理层，建设统一的人事主数据和流程管理平台。系统以员工全生命周期为主线，覆盖员工档案、合同证书、教育与工作经历、组织岗位、职级编制、入转调离、考勤假勤、绩效培训、人事报表、告警通知与附件归档。

系统目标不是只做信息登记，而是形成“数据台账 + 审批流程 + 权限审计 + 报表分析 + 验收归档”的闭环。

## 建设目标

| 目标 | 说明 | 验收口径 |
|---|---|---|
| 员工主数据统一 | 员工基础信息、任职信息、合同、证书、经历集中维护 | 员工详情信息完整、可查询、可导出 |
| 组织岗位清晰 | 组织架构、岗位体系、职级、编制统一管理 | 部门岗位人员关系准确 |
| 流程线上闭环 | 入职、转正、调岗、离职、请假、加班等流程线上审批 | 每个流程有状态、节点、审批记录 |
| 权限与审计可控 | 角色、菜单、按钮、数据范围、附件访问受控 | 越权访问被拒绝且有审计日志 |
| 报表辅助决策 | 人员结构、异动、合同到期、考勤、绩效、培训可统计 | 指标口径明确，报表可导出 |
| 工程可持续迭代 | GitHub PR、CI、Release、验收文档规范化 | 版本可追溯、可回滚、可验收 |

## 用户角色

| 角色 | 主要诉求 | 权限边界 |
|---|---|---|
| 系统管理员 | 维护用户、角色、菜单、字典、系统参数 | 全局配置权限，不直接处理薪资敏感明细 |
| HR 管理员 | 管理员工档案、组织岗位、合同、证书、入转调离 | 可查看全公司人事数据 |
| HR 专员 | 维护指定模块，如招聘入职、培训、合同、考勤 | 按岗位授权访问模块 |
| 部门主管 | 审批下属流程，查看本部门人员与绩效 | 仅本部门及下级部门数据 |
| 普通员工 | 查看本人档案、合同、假勤、培训，提交申请 | 仅本人数据 |
| 财务专员 | 查看薪酬基础数据、成本中心、社保相关统计 | 薪酬相关数据需单独授权 |
| 高管/审计 | 查看组织指标、审计日志、关键报表 | 只读权限，数据范围按授权 |

## 重点业务对象

- 员工：基础信息、任职信息、状态、入职日期、离职日期。
- 组织：公司、部门、团队、上级组织、负责人。
- 岗位：岗位名称、岗位序列、职级、编制、在岗人数。
- 合同：合同类型、期限、签署日期、到期日期、附件。
- 证书：证书名称、编号、有效期、发证机构、附件。
- 经历：教育经历、工作经历、项目经历。
- 流程：入职、转正、调岗、离职、请假、加班、补卡、培训报名。
- 报表：人员结构、异动趋势、合同到期、考勤异常、绩效分布、培训完成率。
