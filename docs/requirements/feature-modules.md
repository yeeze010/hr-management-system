# 功能模块清单

## 模块总览

| 模块 | 子功能 | 优先级 | 说明 |
|---|---|---|---|
| 系统管理 | 用户、角色、菜单、字典、参数、审计日志 | P0 | 所有模块的基础能力 |
| 组织岗位 | 组织架构、岗位、职级、编制、负责人 | P0 | 支撑员工任职与数据权限 |
| 员工档案 | 基础信息、任职信息、合同、证书、经历、附件 | P0 | 人事主数据核心 |
| 入转调离 | 入职、转正、调岗、离职、交接、归档 | P0 | 员工生命周期流程 |
| 考勤假勤 | 考勤记录、请假、加班、补卡、假期余额 | P1 | 员工日常运营 |
| 绩效管理 | 周期、目标、自评、主管评分、结果归档 | P1 | 人才评价 |
| 培训管理 | 培训计划、课程、报名、签到、考试、记录 | P2 | 员工成长档案 |
| 合同证书 | 合同模板、合同台账、证书台账、到期提醒 | P0 | 合规与提醒 |
| 报表中心 | 人员结构、异动、合同、考勤、绩效、培训 | P1 | 管理分析 |
| 通知告警 | 待办、站内信、邮件、企业微信、规则配置 | P1 | 流程驱动 |
| 文件附件 | 上传、预览、下载、权限、归档、MinIO 存储 | P0 | 合同与资料归档 |

## 员工档案

### 基础信息

- 员工编号、姓名、性别、出生日期、证件类型、证件号码。
- 手机号、邮箱、紧急联系人、联系地址。
- 员工状态：待入职、试用、在职、停薪留职、离职。

### 任职信息

- 所属公司、部门、岗位、职级、直属主管。
- 入职日期、转正日期、工龄、司龄。
- 成本中心、用工类型、办公地点。

### 合同

- 合同编号、合同类型、签署日期、开始日期、结束日期。
- 试用期、合同状态、续签记录、合同附件。
- 到期提醒：提前 90/60/30/7 天。

### 证书

- 证书名称、证书编号、发证机构、获取日期、有效期。
- 适用岗位、证书状态、附件。
- 到期提醒：提前 60/30/7 天。

### 经历

- 教育经历：学校、专业、学历、起止时间、证明附件。
- 工作经历：公司、岗位、起止时间、离职原因。
- 项目经历：项目名称、角色、时间、成果。

## 组织岗位、职级编制

- 支持树形组织结构，部门可启停用。
- 岗位归属部门，支持岗位序列、职级、编制人数。
- 编制校验：调岗、入职时检查岗位编制余额。
- 超编处理：允许提交例外审批并生成风险提醒。

## 入职转正调岗离职

- 入职：预入职档案、材料清单、账号开通、入职确认。
- 转正：试用期提醒、自评、主管评价、HR 复核。
- 调岗：原岗/新岗、职级、生效日期、多节点审批。
- 离职：离职申请、交接清单、财务结算、账号停用、档案归档。

## 考勤请假加班

- 考勤导入、异常识别、缺卡补卡。
- 请假类型、余额、审批、销假。
- 加班申请、加班时长确认、调休或薪资口径。
- 月度考勤汇总与导出。

## 绩效

- 绩效周期和评价模板。
- 员工自评、主管评分、HR 校准、员工确认。
- 结果等级、绩效面谈、归档。

## 培训

- 培训计划、课程、讲师、对象范围。
- 报名、签到、学习记录、考试成绩。
- 培训完成率和个人培训档案。
